✅ MUST-HAVES (Before Going Live)
1. Secure Authentication
 ✅ Email/password auth implemented (bcrypt, 12 rounds).
 ✅ Prevent duplicate email registrations with user-friendly error message.
 ☐ Add Google OAuth for smoother signups and anti-spam protection.
 ✅ Session security: MongoDB session store, httpOnly + sameSite cookies, secure in production,
    14-day rolling expiry, session regenerated on login.
 ✅ Forgot / reset password by email (tokens hashed, 1 hour expiry, single use).

2. Authorization Middleware
 ✅ requireLogin applied to every app route (dashboard, transactions, budgets, goals, recurring, reports, settings).

3. User Data Isolation
 ✅ Every query filters by the signed-in user (tests cover cross-user edit/delete attempts).

4. Form and Input Validation
 ✅ Server-side validation for all forms (amounts, dates, categories, lengths, emails, passwords).
 ✅ Output escaped by EJS; CSV export guards against spreadsheet formula injection.

5. Error Handling
 ✅ Express 5 catches async errors; custom 404 / error page; server errors logged.

🚧 SHOULD-HAVES (Before First Real Users)
6. MVC Architecture
 ✅ Controllers, routes, services, middlewares, models, utils separated.

7. User Experience
 ✅ Toast feedback after every action; forms keep input after validation errors.
 ✅ Responsive UI (sidebar on desktop, drawer + floating add button on mobile), dark mode.
 ✅ Charts: cash flow, category doughnut, report trends.

8. Security Enhancements
 ✅ helmet (strict CSP with nonces)
 ✅ express-rate-limit on login/register/password reset
 ✅ CSRF protection on all forms
